## 3. EVALS_NOT_RUN — PROVIDER_NOT_AUTHORIZED

The four UI-brief cases (85 logistics, 86 landing, 87 shop, 88 redesign) grade the skill's **written plan** from a brief. They were **not run**, and no score, pass/fail or delta is claimed for them anywhere.

Reason: no authorised model provider is available to run billable evaluations of this project, and no personal provider is configured. Running them is gated on an authorised provider and an explicit budget. The method is ready: the controlled A/B, the isolated temporary profile and the minimal probe and pilot commands are documented in `docs/review/v1.5.0-eval-proposal.md`. This gap is a **proxy measurement of plan quality**, not of the shipped software, which §1 covers.
