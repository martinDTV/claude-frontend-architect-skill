# `design-system-inventory` — JSON contract v1 (1.8 increment 1, design freeze)

Status: **frozen for implementation; no script exists yet.** Fixture: `verification/tools/fixtures/ds-inventory-nuxt/`
with `truth.json` written from the sources before any code. Decisions taken for the plan's §7 (recommended options):

1. Default roots: `components/ui`, `components/design-system`, `app/components/ui`, `app/components/design-system`,
   plus the same paths inside every Nuxt layer the config `extends` (layers included by default, each component
   carries its `layer`). Override with `.frontend-audit.json` → `designSystem.roots`.
2. `--agents` **prints** the Markdown section to stdout (like every other script); the caller decides where it goes.
3. The starter (increment 5) is **Nuxt UI only** in 1.8.
4. `frontend-reviewer` runs the inventory in its default sweep **when a root exists**; silent otherwise.

## Invocation
`node scripts/design-system-inventory.mjs <project-root> [--json|--md|--agents] [--engine auto|semantic|lexical]
[--fail-on confirmed|heuristic|none]`. Read-only, dependency-free, same `.frontend-audit.json` keys as the other
tools (`exclude`, `engine`), plus `designSystem: { roots, barrel, ejectMarker }`. Exit 0 = no finding at or above
`--fail-on` (default `confirmed`); 1 = findings; 2 = could not run (no root, unreadable project).

## Output (`--json`)
```
{
  tool: "design-system-inventory", version: TOOL_VERSION, generatedAt, root,
  analysis: { engine: "semantic"|"lexical", requested, reason|null },          // same shape as the graph tools
  library: { name: "@nuxt/ui"|"shadcn-vue"|"primevue"|"reka-ui"|null, version: string|null, source: "package.json"|"node_modules"|null },
  roots: [string],                                                             // the roots that exist, repo-relative
  barrel: string|null,                                                         // the public index.ts, if any
  components: [ {
    file, name, layer: string|null,
    owner: "project" | "library-wrapper" | "ejected-copy",                     // what the source IS
    wraps: string|null,                                                        // library component a wrapper renders at its root
    public: boolean,                                                           // exported from the barrel (no barrel → every root component is public)
    documented: boolean,                                                       // a leading HTML/JS doc comment, a `@example`, or a sibling *.md / *.stories.*
    props:  { resolution: "declared"|"declared-type"|"spread-from-import"|"unresolved", names: [..], defaults: {..}, spreadFrom: [..] },
    emits:  [string], slots: [string] ("*" = forwards all), models: [string],  // defineModel names; "modelValue" for the default
    variants: { source: "tailwind-variants"|"cva"|"nuxt-ui-ui-prop"|"app-config"|"data-attributes", axes: { name: [values] } } | null,
    tokens: { used: ["--var", ...], literals: number },                       // CSS custom properties referenced; colour/size literals COUNTED only (design-consistency owns the findings)
    dataView: { states: [...], missing: [...] } | null,                       // only for components that render fetched/async data
    ejected: { from, version, drifted: boolean } | null                        // from the `@ds-ejected` marker; drifted = sha256 of the body ≠ marker
  } ],
  tokens: { declared: [..], unused: [..] },                                    // from the project's token stylesheet(s), unused = declared and referenced by no component
  findings: [ { id, level, file, line, message, evidence } ],
  summary: { components, public, undocumentedPublic, passThroughWrappers, ejected, drifted, dataViews, dataViewsMissingStates, byLevel: {confirmed, heuristic, info} }
}
```

## Findings v1 (ids are public identifiers once shipped)
| id | level | when |
|---|---|---|
| `undocumented-public-component` | confirmed | `public` and not `documented` |
| `pass-through-wrapper` | confirmed | `owner = library-wrapper`, no props, no emits, no models, no script behaviour beyond `defineOptions`/`$attrs`, forwards slots |
| `data-view-missing-states` | heuristic | `dataView` present and `missing` non-empty (a data view is recognised by an async/pending/status prop or `useAsyncData`/`useFetch` in the component) |
| `ejected-copy-drifted` | confirmed | marker present and body hash ≠ marker hash |
| `props-partially-resolved` | info | `props.resolution` is `spread-from-import` or `unresolved` — the list is not the whole API |

Never a finding: literals (owned by `design-consistency`), a11y (owned by `ui-audit`), private undocumented components.

## `--agents` (printed Markdown)
A section titled `## Design system (generated by design-system-inventory — do not edit)` with: the library and
version; the token roles in use; one table of the **public** components (name, one-line doc or "undocumented",
props with defaults, emits, models, slots, variant axes); the rules that follow from the doctrine (import from the
barrel; use tokens not literals; data views render the five states; eject with the marker and refresh it). Dense,
no prose padding — the Vue counterpart of `astryx docs --dense`.

## Honesty bounds (stated in the report's `Analysis` line and in SKILL.md)
Static: never renders; runtime-computed props/variants are `heuristic` or `unresolved`; the library's own
internals are not inventoried, only the project's components; `documented` is presence, not quality.

## Ejection marker convention (doctrine, introduced here)
First line of an ejected component: `<!-- @ds-ejected from="<registry>/<name>" version="<v>" sha256="<hash of the file without this line>" -->`.
Refreshing the hash is part of editing an ejected component; a stale hash is the drift signal.
