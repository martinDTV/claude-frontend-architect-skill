# Gradual evaluation plan (1.7 increment 1, prepared, NOT executed)

A cost-controlled ladder from fully-offline checks to human review. Each rung is only climbed with its
evidence tier's authorization. Nothing below has been run except rung 0.

## The ladder

| Rung | Tier | What runs | Model? | Cost | Authorization | Status |
|---|---|---|---|---|---|---|
| 0 | E0A | `plugin-check.mjs`, `eval-inventory.mjs`, the audit scripts vs fixtures, `transcript-assert` adversarial tests | none | free | none | **DONE (this increment)** |
| 1 | E0B | agent runs a bounded subset (Haiku, 1 run, ceiling); deterministic graders over the transcript | yes (cheap) | small, bounded | your OK + `--max-cost-usd` | NOT_RUN |
| 2 | E1 | add the judge grade (`--judge-model haiku` first) | yes + judge | moderate | your OK + budget | NOT_RUN |
| 3 | E1 (RC) | full suite, stronger agent/judge, for a release candidate | yes + judge | highest | your explicit budget | NOT_RUN |
| 4 | E2 | human reviews the visual/UX contact sheet | human | human time | you | HUMAN_REVIEW_REQUIRED |

## Rung-0 (offline) — what is already verifiable with no model

- Structural well-formedness of all 95 cases (`plugin-check`).
- The evidence-tier classification and recorded state (`eval-inventory` → `docs/eval-inventory.md`).
- The audit tools' precision/recall vs the fixtures with ground truth (the existing tool tests + benchmarks).
- The E0B graders themselves are correct and un-foolable (the adversarial `transcript-assert` tests:
  a faked tool run, a wrong-line citation, an invented file, an incomplete abstention — all rejected).

This is the honest extent of what can be stated today: the suite is well-formed and the graders are
sound; **no behaviour has been measured.**

## Proposed first pilot (small, bounded — pending your approval; do not run yet)

- **Scope:** the `smoke` subset (8 cases: 01, 08, 21, 23, 34, 44, 45, 48 per `docs/evals.md`), both arms,
  1 run each, agent and judge both Haiku.
- **Why this subset:** it already exists as a named low-cost suite, mixes say-no / refusal / activation /
  the 80k-line decision, and is designed to stay under 5 USD.
- **Command (illustrative, NOT executed):**
  `verification/evals/run-evals.sh` with the smoke tag, `MODEL=claude-haiku-5-5`, `RUNS=1`,
  `--max-cost-usd 5`, `--no-publish`.
- **Provider:** a **personal authorized provider only**, configured by you. **No corporate credential,
  no government credential, no unauthorized external provider.** Under Vertex, `run-evals.sh` exports
  `GOOGLE_APPLICATION_CREDENTIALS` when present (a documented gotcha).
- **Estimated cost:** ≤ 5 USD (Haiku), hard-capped by `--max-cost-usd 5`, which aborts with partial
  results if exceeded.
- **What a pass would mean:** only that the smoke cases behave as specified at v1.6.0 under Haiku — a
  first behavioural data point, not a full baseline, and explicitly Haiku-not-Sonnet.

## Rules that never relax

- No rung is declared "approved" on evidence from a lower rung. A rung-1 PASS is not a rung-2 (quality)
  PASS; a rung-0 structural pass is never a behavioural pass.
- No E2 (visual/UX) verdict is produced by any automated rung; axe/Lighthouse/vitals passing is rung-0
  objective evidence, never "good design".
- Cases 85–88, 89–95 stay NOT_RUN until their rung is authorized and actually run.
- Every model run carries `--max-cost-usd`. No exceptions.
