## Interpretation of the deficiencies found

The corpus deliberately set out to find real limits, not perfect scores. The confirmed limits:

- **state recall gap (1 FN):** `state-audit` grades web-storage writes on the literal text of the key/value
  identifiers and does no variable resolution, so `localStorage.setItem(KEY, t)` where `KEY='auth:jwt'` and
  `t=data.accessToken` are separate bindings is missed. A dataflow-aware auditor would catch it.
- **routes precision cost (2 FP):** `routes-audit` matches auth/validation by a name vocabulary in the handler
  body; when authorization lives in an imported helper (`ensureLoggedIn()`) or validation in `assertValid()`,
  the single-file lexical check over-fires. Strong recall, a precision cost exactly on cross-file enforcement.
- **perf recall gap (2 FN):** `heavy-static-import` iterates only imports of kind `static`, so a heavy module
  pulled in via `export … from` (re-export) or a bare side-effect import escapes it; and `computed-side-effect`
  matches effect tokens only in the getter's own body, missing an effect one call-level deep (no call graph).
- **documented out-of-scope blind spots (not counted as FN):** `ui-audit` names only native elements, so a
  custom `<div role="textbox">` with no accessible name is a real widget-level recall gap it does not claim to
  cover; `route-attribution` reports up to route-associated bytes, never transferred/used (needs a browser).

## Limits of generalization (honest scope)

- arch, a11y and bundle scored 100% on their 8/8/6 cases, but a clean sweep means only that this slice
  exercises behaviors the tool handles; it does NOT prove the tool is defect-free. The hardest traps built
  (barrel re-exports, type-only severity, lazy-but-large chunks, the 149.8 KB knife-edge, encapsulated labels,
  aria-labelledby) are passed; harder territory (the semantic engine with --follow-reexports/--typecheck,
  dependency-policy pairs, custom ARIA widgets, transferred bytes) is future work.
- Every case is a small synthetic app. Real codebases are larger and messier; these numbers characterize the
  detectors on controlled inputs, not recall on patterns the corpus does not contain (the same caveat the
  existing benchmarks.md states for the semantic engine).
- The corpus is a development set: it was authored and measured in one pass. A held-out validation set is noted
  as future work; today's numbers are an in-sample characterization.
- Defect levels: route-attribution's signal is heuristic, routes/perf findings here are mostly heuristic; a
  heuristic is a lead to verify, not a confirmed verdict — the measurer records min-level partials separately.
